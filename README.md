# Online Food Ordering System

A simple Java-based Online Food Ordering System developed using Core Java, JDBC, and MySQL.

## Features

- Customer Registration
- View Menu
- Place Order
- Order History
- Bill Generation
- View Customers

## Technologies Used

- Java
- JDBC
- MySQL
- Eclipse IDE

## Database

food_ordering

## Tables

- customers
- menu
- orders
- order_items

## Concepts Used

- JDBC
- SQL
- PreparedStatement
- CRUD Operations
- JOIN
- Master-Detail Relationship
- Transactions
- Exception Handling
- Scanner

## How to Run

1. Install Java and MySQL.
2. Create the `food_ordering` database and tables.
3. Add MySQL Connector/J to the project.
4. Update MySQL username and password in `Main.java`.
5. Run `Main.java` as a Java Application.
